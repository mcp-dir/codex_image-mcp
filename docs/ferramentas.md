# Ferramentas

Codex Imagem expõe 2 ferramentas (todas somente leitura).

### 1. `codex_image_generate`
**Input**: `prompt`, `account` (opcional)

Gera uma imagem a partir de um texto, usando a cota de imagens da assinatura ChatGPT conectada (não consome créditos de API).

### 2. `codex_image_subscription`
**Input**: `account` (opcional)

Mostra qual assinatura ChatGPT está conectada (e-mail e plano).

## Prompts de exemplo

```
Gere uma imagem de um mascote de raposa para a minha marca, estilo flat
Crie uma foto de produto de uma caneca de cerâmica em fundo claro
Qual assinatura do ChatGPT está conectada aqui?
```
